# 企业项目交付规范（校企基地）

## 1. 交付物清单

| 序号 | 交付物 | 格式 | 必需 |
|------|--------|------|------|
| 1 | 可运行源码 | ZIP | 是 |
| 2 | 阶段总结 | Markdown | 是 |
| 3 | 部署与接口说明 | Markdown 或 PDF | 是 |

## 2. 代码仓库约定

- 分支：`develop` 集成功能，`main` 仅放稳定里程碑  
- 提交信息须说明模块与 issue（如有）  
- 禁止提交密钥、生产数据库连接串  

## 3. 文档要求

- 部署文档须含：环境版本、启动命令、默认账号、已知问题  
- 接口说明须含：核心 API 路径、请求示例、错误码  

## 4. 验收节点

- 阶段末演示 MVP 流程（库存低于阈值 → 触发通知）  
- 导师签字确认后，在平台「确认发布」成绩
