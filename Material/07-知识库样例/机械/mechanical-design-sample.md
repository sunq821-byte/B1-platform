# 机械设计基础 · 减速器设计说明书（结构参考）

**课程**：机械设计基础（ME301）  
**题目**：单级斜齿圆柱齿轮减速器设计  
**提交人**：韩磊  
**日期**：2026-07-14  

## 1. 设计任务

设计用于带式输送机的单级斜齿圆柱齿轮减速器，输入功率 3 kW，输入转速 960 r/min。

## 2. 方案论证

采用展开式布局，齿轮浸油润滑，联轴器选用弹性柱销式。

## 3. 主要参数

| 项目 | 数值 |
|------|------|
| 传动比 | 4.2 |
| 小齿轮齿数 | 24 |
| 大齿轮齿数 | 101 |
| 模数 | 2 mm |

## 4. 强度校核

接触强度与弯曲强度均满足 GB/T 3480 要求，安全系数 ≥ 1.2。
