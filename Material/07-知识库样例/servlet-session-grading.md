# 评分细则 — Servlet 会话管理实训（R/S/R/O）

## 完成度 (Completion)
- **R**：登录、登出、会话超时检测流程完整
- **S**：Filter 统一拦截未登录请求
- **R/O**：缺登出或超时处理扣 10～15 分

## 规范性 (Standard)
- **R**：使用原生 Servlet API，无框架混用
- **S**：web.xml 或注解配置清晰，命名规范
- **R/O**：直接 JSP 混写业务逻辑扣 8 分

## 质量 (Quality)
- **R**：会话固定、空指针等基本问题已处理
- **S**：异常页面友好，日志可追踪
- **R/O**：会话未销毁导致内存泄漏扣 5 分

## 表达与完整性 (Expression)
- **R**：README 含部署步骤与运行截图
- **S**：说明 Session 生命周期与测试用例
- **R/O**：无 README 扣 5 分；无截图扣 3 分
