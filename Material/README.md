# 衡迹（B1）演示素材库

本目录存放**可被系统真实使用**的演示素材（上传、下载、试交、复核均走 MinIO + `file_storage`）。

启动后端（`dev` 配置）时，`MaterialSeedRunner` 会按 `manifest.json` 将素材同步至 MinIO；数据库种子见 Flyway `V11__rich_demo_data.sql`。

---

## 目录结构

| 目录 | 用途 | 当前状态 |
|------|------|----------|
| `01-源码示例/` | 学生可打包提交的示例源码（Java / Vue / Servlet） | ✅ 已含 3 套 |

| `06-评分细则/` | 教师建任务时的 R/S/R/O 细则样例 | ✅ 已含 2 份 |
| `07-知识库样例/` | 教师知识库 P1 功能演示文档 | ✅ 已含 2 份 |

## 建议补充的素材（请你按需添加）

### 高优先级（直接影响演示效果）

- [ ] **真实 PDF 实训报告**（2～3 份，含封面、目录、截图）
- [ ] **完整 Spring Boot 项目 zip**（可运行，非单文件示例）
- [ ] **Vue3 组件库完整工程 zip**（含 `package.json`）
- [ ] **教师复核页截图**（1920×1080 PNG）
- [ ] **学生成绩雷达图截图**（PNG）

### 中优先级（丰富「成熟系统」观感）

- [ ] **课程封面图**（每门课 1 张，16:9 JPG）
- [ ] **用户头像**（admin / teacher / student 各 1 张）
- [ ] **MinIO 大文件样例**（接近 50MB 上限，测上传限制）
- [ ] **Git 仓库 README** 导出 zip（模拟 GIT 提交方式）
- [ ] **Excel 班级花名册**（管理员导入用，P1）

### 低优先级 / P1 扩展

- [ ] **企业导师评价样例**（Word/PDF）
- [ ] **学院报表导出样例**（PDF/Excel）
- [ ] **操作手册 PDF**（管理员培训）
- [ ] **宣传视频封面**（MP4 封面图即可）

## 手动同步到 MinIO

```powershell
cd D:\Project\B1\Material\scripts
.\sync-to-minio.ps1
```

或启动后端（dev 环境会自动同步）。
