## 2 产品概述

### 2.1 产品简介

B1 智慧实训平台是面向高校软件类专业实训教学全流程的智能化管理与评价平台。系统采用网页端运行方式，无需下载安装，覆盖「课程管理 → 实训发布 → 标准配置 → 成果提交 → 智能分析 → 教师审核 → 能力成长 → 教学复盘」完整业务闭环。平台以 AI 大模型辅助教学评价，学生提交后即时获得诊断反馈，教师批改工作量可降低 60% 以上。

![系统首页截图](../prototypes/screenshots/02-dashboard-student.png)

### 2.2 主要功能总览

**学生端功能**：课程查看、任务接收、成果提交（文件上传 / Git URL）、AI 诊断结果查看、成绩查看、个人报告生成、成长中心

**教师端功能**：课程管理、实训任务发布、评价标准配置、AI 诊断查看、学生复核评分、催办提醒、报表统计（班级学情 / 学院质量 / 跨班对比）、学生管理

**管理员端功能**：系统总览、用户管理、班级管理、运行监控、操作日志、系统配置

### 2.3 产品特色

- **免安装**：打开浏览器即可使用，无需下载安装包，适配电脑端操作；
- **AI 智能评价**：学生提交实训成果后自动触发大模型多维度分析，即时获得诊断反馈和改进建议；
- **高效批改**：AI 自动初评结合人工复核，大幅减少教师重复性批改工作；
- **全流程数字化**：覆盖实训教学从课程创建到教学复盘的全链路，满足归档与督导要求。

### 2.4 性能与安全说明

**性能说明**：常规操作页面加载时间不超过 2 秒，成果提交、AI 分析等核心操作响应流畅。AI 分析过程通过流式输出实时展示进度，用户无需等待。

**安全说明**：系统采用 Sa-Token + JWT 认证机制，用户密码加密存储；所有关键操作留有日志记录，保障账号与数据安全；AI 密钥通过环境变量注入、不入库存储。

## 3 运行环境要求

### 3.1 电脑端运行环境

- 操作系统：Windows 10 / Windows 11 / macOS 10.15 及以上
- 浏览器：Chrome 90+、Edge 90+、Firefox 90+（推荐使用 Chrome 或 Edge）
- 网络：需连接互联网，AI 分析功能需稳定网络环境
- 分辨率：建议 1366×768 及以上

### 3.2 移动端说明

本系统当前版本面向电脑端浏览器设计，移动端浏览器可进行基本浏览操作，但部分管理功能在移动端体验可能受限。

## 4 公共功能

### 4.1 登录与鉴权

系统采用基于 Sa-Token 的 JWT 认证机制，支持统一登录页面。登录后根据角色自动跳转对应仪表盘。

**登录页面**：输入用户名和密码，系统校验后生成 Token 并写入请求头，后续请求自动携带。

![登录页面](../prototypes/screenshots/01-login.png)

### 4.2 导航系统

顶部导航栏包含系统 Logo、主导航菜单（按角色动态展示）、通知铃铛、用户头像下拉菜单（个人中心 / 修改密码 / 退出登录）。

### 4.3 通用交互规范

- 数据表格支持分页、排序、筛选
- 表单提交后即时反馈（成功 Toast / 错误提示）
- 加载状态展示骨架屏或 Loading 动画
- 空数据展示 Empty State 引导文案
- 错误场景展示 Error State 与重试按钮
- 403/404 页面提供友好导航

### 4.4 通知系统

顶部导航栏通知铃铛实时显示未读通知：任务发布通知、催办提醒、成绩公布通知、系统公告。支持单条已读和全部已读。

## 5 功能操作说明

### 5.1 学生端功能

学生端共 7 个功能页面，覆盖从课程查看到个人成长的全流程。

#### 5.1.1 学生仪表盘

登录后首页，卡片展示关键数据：课程数量、待提交任务数、已批阅成绩数、AI 评测平均分。下方展示近期任务列表和课程概览。

![学生仪表盘](../prototypes/screenshots/02-dashboard-student.png)

#### 5.1.2 课程列表

展示当前学期所有已选课程，包含课程名称、授课教师、进度、任务完成情况。点击进入课程详情。

#### 5.1.3 课程详情

展示单个课程下的全部实训任务列表，含任务名称、截止时间、提交状态（未提交 / 已提交 / 已批阅）、成绩。支持点击进入任务详情。

#### 5.1.4 任务详情

展示任务描述、实训要求、提交方式（文件 / Git URL）、截止时间。已完成提交的展示提交记录和 AI 评分结果。

#### 5.1.5 成果提交

![提交页面](../prototypes/screenshots/07-submission.png)

支持两种提交方式：
- **文件上传**：支持 ZIP / PDF / DOC / 代码文件，拖拽或点击上传，单文件最大 50MB；
- **Git URL**：输入仓库地址，系统自动验证仓库可访问性。

提交后自动触发 AI 分析（如已配置），学生可实时查看分析进度。

> ⚠️ 注意：提交截止时间过后将无法提交，请留意任务截止时间。提交后请在 AI 分析完成前不要关闭页面。

#### 5.1.6 AI 诊断结果

![AI 分析](../prototypes/screenshots/09-ai-analysis.png)

展示 AI 多维度评分卡（雷达图 + 维度得分），包含：各维度得分与满分对比、扣分项明细、改进建议。

#### 5.1.7 成绩查看

![学生成绩](../prototypes/screenshots/08-student-grades.png)

展示各课程实训任务的最终成绩（AI 初评 + 教师复核后），支持按课程筛选。可查看单次实训的详细评分明细。

#### 5.1.8 个人报告

生成学生个人实训档案报表，包含：分数趋势折线图（跨学期对比）、能力雷达图（多维度能力分布）、实训成果列表。支持导出 PDF 和 Excel。

#### 5.1.9 成长中心

![成长中心](../prototypes/screenshots/10-growth-center.png)

展示学生学习成长轨迹：学期实训分数演变、能力维度变化趋势、学习建议。

### 5.2 教师端功能

教师端共 11 个功能页面，覆盖课程管理、任务发布、AI 诊断、成绩复核、报表统计。

#### 5.2.1 教师仪表盘

![教师仪表盘](../prototypes/screenshots/03-dashboard-teacher.png)

概览当前学期教学情况：授课课程数、学生总数、待批阅提交数、平均完成率。展示近期提交列表和课程分布。

#### 5.2.2 课程管理

![课程管理](../prototypes/screenshots/13-course-management.png)

支持创建、编辑、归档课程。课程信息包括：课程名称、课程代码、学期、学分、课程描述。支持为课程关联学生和配置评价标准。

#### 5.2.3 实训任务管理

![实训管理](../prototypes/screenshots/14-training-management.png)

在课程下创建和管理实训任务：
- 任务名称、描述、实训要求
- 提交方式（文件上传 / Git URL / 混合）
- 截止时间、最大提交次数
- 评分标准关联
- 批量发布到多个班级

> ⚠️ 注意：截止时间一旦设定，学生不可逾期提交。批量发布前请确认班级选择正确。

#### 5.2.4 学生管理

查看和管理课程下的学生列表，查看学生提交状态、成绩概况。支持搜索和筛选。

#### 5.2.5 提交审核

![教师评审](../prototypes/screenshots/11-teacher-review.png)

查看学生提交的实训成果，包含：
- **代码文件预览**：在线查看 ZIP 包内代码文件；
- **AI 诊断结果**：查看 AI 对本次提交的多维度分析；
- **人工复核**：对 AI 评分进行采纳/调整，添加教师评语；
- **终审操作**：通过 / 驳回 / 退回重提。

> ⚠️ 注意：终审操作为不可逆操作，确认前请仔细核对评分。

#### 5.2.6 催办提醒

对未提交任务的学生发送催办通知，支持单选和批量催办。被催办学生会在通知铃铛中收到提醒。

#### 5.2.7 报表中心

![报表中心](../prototypes/screenshots/12-report-center.png)

- **班级学情报表**：班级整体成绩分布、任务完成率、分数段统计；
- **学院教学质量报表**：跨班级对比分析、学期趋势；
- **跨班对比**：柱状图对比不同班级同一任务表现。

支持导出 PDF 和 Excel 格式。

#### 5.2.8 评价标准管理

![评价标准](../prototypes/screenshots/17-evaluation-standards.png)

定义评价维度与权重配置，支持模板库功能（预置模板一键复制复用）。系统固定四维评价框架（完整性 / 规范性 / 正确性 / 创新性），教师可为每个任务配置自定义评分细则。

### 5.3 管理员端功能

管理员端共 6 个功能页面，导航顺序如下：

**系统总览 → 用户管理 → 班级管理 → 运行监控 → 操作日志 → 系统配置**

#### 5.3.1 系统总览

![管理员仪表盘](../prototypes/screenshots/05-dashboard-admin.png)

平台运维概览：用户规模与今日活跃、AI 调用 / 对象存储 / 异常告警、服务健康、角色分布、最近操作日志。支持一键跳转「新建用户」与各管理页。

#### 5.3.2 用户管理

![系统管理](../prototypes/screenshots/15-system-admin.png)

- 用户账号管理（新建 / 编辑 / 角色分配 / 状态启停）
- 角色说明合入本页（不单独设置权限矩阵页）
- 批量导入入口预留（后续版本开放）

> 注意：删除用户为高危操作，已关联课程或提交记录的用户不可删除。

#### 5.3.3 班级管理

- 班级创建 / 编辑 / 删除
- 班主任与学生人数维护

#### 5.3.4 运行监控

- CPU / 内存 / 磁盘 / 运行时间
- 依赖服务健康状态

#### 5.3.5 操作日志

- 系统关键操作审计
- 支持按类型筛选；展示时间、用户、操作、IP、结果

#### 5.3.6 系统配置

- 系统名称、当前学期与起止日期
- 上传大小限制、AI 自动分析、通知开关、维护模式

## 6 AI 功能说明

### 6.1 AI 自动评分

学生提交实训成果后，系统自动调用大模型进行多维度分析评分：

- **代码规范性检测**：语法规范、命名规范、代码格式
- **功能完整性校验**：需求覆盖率、核心功能实现
- **创新性评估**：方案的创新程度和扩展性
- **报告质量**：文档完整性和规范性

### 6.2 流式输出

AI 分析过程通过 SSE（Server-Sent Events）实时推送，前端以打字机动画展示分析进度和结果。

### 6.3 AI 限制与安全保障

- AI 仅提供建议评分，最终分数由教师确认；
- 所有 AI 输出可追溯、可复核；
- 支持超时降级：AI 调用超时自动返回降级结果并提示；
- AI 密钥不入库，通过环境变量注入。

## 7 常见问题与故障排查

### 7.1 常见系统提示说明

| 提示信息 | 产生原因 | 解决方法 |
|---|---|---|
| 用户名或密码错误 | 账号或密码输入错误，或区分大小写 | 核对学号 / 工号，确认密码大小写；忘记密码联系管理员重置 |
| 无权限访问该页面 | 当前账号没有对应功能的操作权限 | 联系系统管理员申请开通对应权限 |
| 文件上传失败 | 文件大小超限（超过 50MB），或文件格式不支持 | 压缩文件后重新上传；确认文件格式为 ZIP、PDF、DOC 或常见代码文件 |
| 提交失败（已过截止时间） | 实训任务已到截止时间 | 联系授课教师确认是否可延期 |
| AI 分析超时 | AI 模型调用响应时间过长 | 稍等片刻，系统会自动返回降级结果；如持续超时，联系技术支持 |
| 操作提示网络异常 | 设备网络连接不稳定 | 检查网络连接，刷新页面后重试 |

### 7.2 典型故障排查方法

**问题 1：页面打开空白、加载不出来**

排查步骤：
1. 检查电脑是否正常联网，尝试打开其他网站确认网络状态；
2. 按键盘 F5 刷新页面，或关闭浏览器重新打开系统地址；
3. 清除浏览器缓存（Chrome：设置 → 隐私与安全 → 清除浏览数据），或更换 Chrome、Edge 浏览器重新访问；
4. 若以上方法均无效，联系技术支持处理。

**问题 2：点击按钮没有反应**

排查步骤：
1. 检查是否有必填项未填写，红色标注的输入框需补充内容；
2. 刷新页面后重新操作，排查是否为页面加载异常；
3. 确认账号是否有对应操作权限，无权限则按钮不可点击。

**问题 3：AI 分析结果一直显示"分析中"**

排查步骤：
1. 等待片刻，AI 分析通常需要 10-30 秒；
2. 刷新页面查看分析是否已完成；
3. 若超过 2 分钟仍未完成，联系技术支持确认 AI 服务状态。

## 8 应急操作指引

- **系统升级维护期间**：系统会提前发布公告，升级期间暂停服务，请避开维护时段操作，升级完成后刷新页面即可恢复。
- **批量操作数据异常**：若批量导入数据后出现异常，请勿重复操作，立即联系管理员处理，避免数据错乱。
- **账号异常登录**：若发现账号非本人登录，请立即修改密码，并联系系统管理员核查操作记录。
- **AI 服务异常**：若 AI 评分功能集体不可用，教师可先行人工评分，AI 服务恢复后不影响已有评分数据。

## 9 维护与升级

### 9.1 日常使用与维护

- **普通用户（学生 / 教师）**：无需特殊维护，定期修改密码保障账号安全即可；
- **管理员**：每日查看系统运行状态，及时处理用户权限申请，每月清理一次过期操作日志；
- **数据安全**：请勿随意删除系统部署目录中的数据库与对象存储数据；例行备份由部署环境运维负责。

### 9.2 版本升级说明

- 系统升级由技术人员在服务端完成，升级前会通过系统公告提前通知用户；
- 升级期间系统将短暂暂停服务，升级完成后自动恢复；
- 用户无需进行任何安装、更新操作，升级完成后刷新浏览器页面，即可使用新版本功能。
