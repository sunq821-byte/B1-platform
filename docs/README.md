## 文档维护原则

1. **产品需求**只维护 `01-PRD`，禁止另起 PRD 造成分叉
2. **接口变更**必须同步更新 `04-API-Contract.md`
3. **表结构变更**必须同步更新 `03-Database-Design.md` 并新增 Flyway 迁移
4. **截图 / 立项 / 软著**等交付物放本地对应目录，不进入 Git
