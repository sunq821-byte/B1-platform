---

## 1. 目标

对管理员、教师、学生每一页按文档统一视觉与信息结构，做到：

1. **简洁明了**：一屏一事，去掉装饰性空壳（假按钮、无筛选项的 filter-bar、无数据的占位模块）。
2. **所见即所得**：页面上出现的控件均可操作或明确标注「后续版本」；展示字段与手册/契约一致。
3. **Campus Blue 一致**：操作蓝 `#1677FF`、状态绿 `#00B96B`、海军蓝 `#0B3A5C`、AI 紫 `#722ED1`；顶栏导航；不抄深色顶栏。

功能与接口不扩 scope；不改业务语义；AI 不输出最终成绩。

## 4. 通用页面骨架（所见即所得）

### 4.1 列表页

```
PageHeader（标题 + 一句副标题，说明本页干什么）
Toolbar / filter-bar
  左：真实筛选（角色 / 类型 / 关键词…）
  右：主操作（新建…）
表格（列 = 手册声明字段）
空态 / 加载态
Dialog 表单（仅编辑本页真实字段）
```

禁止：

- 只有「新建」却没有筛选时仍占一整条空 filter-bar（应把新建收到 Header actions 或 Toolbar 右侧）
- 「批量导入」等未开放能力做成可点主按钮（改为 outline + 明确提示，或隐藏）
- 假「+ 新建学期」等无法落库的入口

### 4.2 监控 / 报表页

```
PageHeader
关键指标行（真实数据）
主内容（服务表 / 图表）
```

无数据则 Empty，不画假图表装饰。

### 4.3 配置表单页

```
PageHeader
分组卡片（基本 / AI / 开关）
底部唯一「保存」
只读列表（如学期历史）不假装可编辑
```

### 4.4 仪表盘

沿用已确认的 `17` / `19` 结构；信息可点击跳转到对应管理页。

## 5. Batch 1 — 管理员 6 页设计要点

导航（已落地）：系统总览 → 用户 → 班级 → 运行监控 → 操作日志 → 系统配置。

| 页面 | 线框 | 结构要点 | 相对现状的清理 |
|---|---|---|---|
| 系统总览 | `19`（已有）+ 实现已落地 | Welcome + 进度胶囊 + KPI / 运行摘要 + 趋势 + 优先处理 / 事件 + 角色 + 快捷台 | 保持；验收时核对后端字段 |
| 用户管理 | `20` §用户 | Header + Toolbar（角色/搜索/新建）+ 表 + 弹窗 | 「批量导入」降级为次要 outline +「后续版本」提示；无删除入口（手册：关联数据不可删，MVP 用启停） |
| 班级管理 | `20` §班级 | Header + Toolbar（搜索 + 新建）+ 表 + 弹窗 | **补搜索**；去掉空 filter-bar 假象 |
| 运行监控 | `20` §监控 | Header + 四资源卡 + 服务表（名称/状态/详情/延迟） | 服务表补详情与延迟（若接口已有则展示，无则不造假列） |
| 操作日志 | `20` §日志 | Header + Toolbar（类型 + 可选关键词）+ 表（时间/用户/操作/IP/结果） | 列与手册一致；类型筛选保留 |
| 系统配置 | `20` §配置 | 双卡表单 + 学期只读表 + 单保存 | 无新建学期；维护模式用危险色标注 |

## 6. 验收标准（每批）

- [ ] 打开页面能在 3 秒内看懂「这页干什么、主操作在哪」
- [ ] 无空壳控件；未开放能力有明确文案
- [ ] 列表页 Toolbar 符合 Design System：左筛右操作或左操作右筛，不混排混乱
- [ ] Campus Blue token，无紫色主题漂移、无玻璃拟态
- [ ] `vue-tsc` 通过；真实后端时字段可归一化不白屏

---

## 7. 非目标

- 不重做登录 / 403 / 404（除非后续单独排期）
- 不引入侧栏、深色顶栏、Resq 品牌导航
- 不扩展备份恢复、权限矩阵独立页、批量导入后端
- 不在本改版中改 AI 评分业务规则
